# EviMon

Official repository for:

**EviMon: Evidence-Grounded Multimodal Large Language Model Reasoning for Robot Failure Detection**

## Overview

EviMon is an evidence-grounded multimodal reasoning framework for robot failure detection. It integrates multimodal observations and structured evidence to identify execution failures and provide interpretable diagnostic reasoning.

## Dataset

We release question-answer (QA) annotations and temporal window annotations constructed from the **REASSEMBLE** benchmark to support robot failure detection and evidence-grounded multimodal reasoning.

### Released Annotations

| File | Description |
|---|---|
| [`train.json`](dataset/train.json) | Training split of the QA annotations. |
| [`test.json`](dataset/test.json) | Test split of the QA annotations. |
| [`cut_manifest.jsonl`](dataset/annotations/cut_manifest.jsonl) | Temporal window annotations for robot execution recordings. |

All annotation files are publicly available in this repository.
